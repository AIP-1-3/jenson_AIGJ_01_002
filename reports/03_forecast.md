# 과제 3. 60분 예측 (GRU)

## 측정 조건
- 데이터: 실데이터 InfluxDB iot-bucket + 수집기, 학습 ~2026-09-21, 검증 ~2026-10-06, 시험 2026-10-06 ~ 2026-10-20 (UTC)
- 대상 공간: 실습실, 사무실, 회의실 (외기 입력: 사무실 밖)
- 입력 120분(24칸) × 15특성, 출력 5~60분 12칸 한 번에, 목표 = 현재값 대비 변화량
- GRU hidden 64, layers 1, dropout 0.1, Adam lr 0.001, batch 256, 에폭 16/40(조기 종료 patience 6, 검증은 일하는 날만), L1 손실, seed 42
- 공휴일 8일은 평일에서 제외, 일정 입력: 있음
- 장비: Jetson Orin Nano Super, PyTorch CPU 3스레드, 평균 에폭 50.2s, 시험 추론 0.052ms/창(배치 4096)
