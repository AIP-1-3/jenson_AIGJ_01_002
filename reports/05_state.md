# 과제 5. 상태 추정

## 측정 조건
- 데이터: 실데이터, 학습 ~2026-09-21, 검증 ~2026-10-06, 시험 2026-10-06 ~ 2026-10-20 (UTC), 5분 간격
- 사용 여부 정답: configs/schedule.yaml (source=placeholder), 직접 관찰 0건 우선 적용. 정답 정보는 입력에 넣지 않음
- 환기 경보 정답: 지금 <1000ppm 이고 30분 안에 ≥1000ppm. 이미 넘은 시점 제외
- 입력 특성 20개: co2, co2_d15, co2_d30, co2_d60, temperature, temperature_d15, temperature_d30, temperature_d60, humidity, humidity_d15, humidity_d30, humidity_d60, co2_max1h, co2_std1h, co2_min3h, co2_above_min, out_temp, hour_sin, hour_cos, weekday
- 환기 경보 임계값: 검증 기간 재현율 ≥85% 인 가장 높은 확률값 / 사용 여부는 0.5

> ⚠ 사용 여부 정답이 임시 가정(평일 9~18시)이다. 실제 시간표로 바꾸면 다시 실행한다.
