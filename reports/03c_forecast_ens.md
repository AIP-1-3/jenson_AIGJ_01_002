# 과제 3 개선(C). GRU 평균 + Chronos-Bolt 섞기

## 측정 조건
- 학습 ~2026-09-21, 검증 ~2026-10-06(일하는 날만), 시험 2026-10-06 ~ 2026-10-20 (UTC)
- 구성원(실행 전 고정): GRU × 과거 60분, 120분, 240분 × 시드 42, 43, 44, 45, 46 = 15개 학습. hidden 64, 에폭 상한 40, patience 6, 일정 입력 있음
- Chronos-Bolt: amazon/chronos-bolt-small (cpu), 예측 735s, 과거 42시간
- w(GRU 평균 대 Chronos 비율)·α(변화량 축소)는 검증 기간에서만 정함. 방식 선택은 검증 기간 날짜 홀짝 교차 맞춤 점수.
- 평가 시점: 시험 기간에서 구성원 중 하나라도 창을 만들 수 있는 (시각, 공간) 12,014개, 현재값 유지도 같은 시점
- 장비: Jetson Orin Nano Super, PyTorch CPU 3스레드, 전체 104분
