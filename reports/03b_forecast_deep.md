# 과제 3 심화. 모델 3종 × 과거 길이 비교, 처음 보는 공간 일반화

## 측정 조건
- 데이터: 실데이터, 학습 ~2026-09-21, 검증 ~2026-10-06(일하는 날만), 시험 2026-10-06 ~ 2026-10-20 (UTC)
- 입력·출력·목표는 과제 3 본 모델과 같음 (변화량 12칸 한 번에, 지평별 α 검증 결정, 공휴일 제외), 일정 입력 있음 (source=timetable)
- 공통 하이퍼파라미터: hidden 64, layers 1, dropout 0.1, Adam lr 0.001, batch 256, L1 손실, seed 42, TCN 채널 48·커널 3·dilation 1,2,4,8,16
- (A) 에폭 상한 20, patience 5 / (B) 에폭 상한 12, patience 4 (시간 예산 때문에 과제 3 본 실행의 40/6 보다 낮춤)
- (A) 설계: 3종 @ 2시간 → 검증 최고 구조(GRU) @ 1·4시간. 최적 조합은 검증 점수(공간별 60분 CO₂ MAE ÷ 현재값 유지 의 평균)로만 고르고, 시험 오차는 보고만 한다.
- 장비: Jetson Orin Nano Super, PyTorch CPU 3스레드, 전체 실행 45분

## 해석 (직접 작성)
- 최적 조합과 근거(검증 점수, 학습 시간·파라미터 대비): 검증 점수가 가장 낮은 GRU 120분 모델(0.809)을 최적 조합으로 선택했다. 파라미터는 17,112개로 LSTM(22,296개)보다 적고 TCN(66,792개)의 약 1/4 수준이다. 학습 시간은 240초로 GRU 60분(72초)보다 길지만, 검증 성능이 더 좋고 시험 기간 세 공간 모두에서 60분 CO₂ 오차가 현재값 유지보다 낮았다. 따라서 정확도와 모델 크기, 연산 비용을 종합적으로 고려했을 때 GRU 120분이 가장 적합하다고 판단했다.
- 과거 길이를 늘리거나 줄였을 때 지평별로 무엇이 달라졌나: GRU 입력을 60분으로 줄이면 60분 예측에서 실습실 오차가 31.82→29.89ppm, 사무실은 40.10→38.53ppm으로 개선됐지만, 회의실은 52.34→56.34ppm으로 악화됐다. 반대로 240분으로 늘리면 회의실의 5분 오차는 10.48→9.88ppm으로 줄었지만, 실습실의 60분 오차는 34.46ppm으로 증가했다. 입력을 길게 사용한다고 모든 예측 지평에서 성능이 좋아지는 것은 아니었으며, 공간별 특성과 예측 시간에 따라 차이가 발생했다. 시험 기간에서 일부 조합의 성능이 더 좋더라도 모델 선택은 검증 점수를 기준으로 유지했다.
- 구조별 차이(GRU·LSTM·TCN)와 Jetson 에서의 비용: 동일한 120분 입력에서 GRU는 검증 점수 0.809로 LSTM(0.816), TCN(0.828)보다 우수했다. LSTM은 파라미터 22,296개, 에폭당 학습 시간 18.2초로 GRU(17,112개, 16초)보다 조금 무거웠다. TCN은 파라미터 66,792개, 에폭당 51.2초로 GRU보다 약 3.2배 오래 걸렸지만 검증 성능은 더 낮았다. 추론 지연도 GRU 0.038ms, LSTM 0.091ms, TCN 0.105ms로 GRU가 가장 빨랐다. Jetson처럼 연산 자원이 제한된 환경에서는 구조를 복잡하게 만드는 것보다 상대적으로 가벼운 GRU를 사용하는 편이 효율적이라고 판단했다.
- 일정 입력이 회의실 예측에 준 효과와 한계(예약표 부재): 일정 입력을 추가하자 회의실의 60분 CO₂ 오차가 54.22ppm에서 52.34ppm으로 약 1.88ppm 감소했다. 하지만 5~30분 예측에서는 개선 폭이 0.06~0.15ppm으로 작았다. 실습실은 60분 오차가 10.29ppm 감소한 것과 비교하면 회의실의 일정 정보는 효과가 제한적이었다. 현재 회의실은 실제 예약표가 없어 평일 9~18시를 사용 시간으로 가정하고 있다. 회의는 정해진 근무 시간과 실제 사용 시간이 다를 수 있기 때문에, 향후 예약 정보를 연결하면 예측 성능이 개선되는지 추가로 확인할 필요가 있다.
- 처음 보는 공간에서 현재값 유지보다 나은가, 포함 학습과 차이는 얼마인가: 특정 공간을 학습에서 제외한 뒤 예측하자 60분 CO₂ 오차 개선율은 실습실 4.56%, 사무실 1.18%, 회의실 −5.06%로 나타났다. 모든 공간을 포함해 학습했을 때의 개선율(20.44%, 13.64%, 7.45%)보다 낮았다. 특히 회의실은 현재값 유지 오차 56.56ppm보다 모델 오차가 59.42ppm으로 높아졌다. 이를 통해 기존 공간에서 좋은 성능을 보인 모델도 처음 보는 공간에서는 성능이 떨어질 수 있음을 확인했다. 새로운 공간에 적용할 때는 초기 데이터를 수집해 성능을 확인하고, 필요하면 해당 공간 데이터로 모델을 재학습하거나 보정해야 한다고 판단했다.
