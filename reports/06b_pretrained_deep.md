# 과제 6 심화. 앙상블 · 공변량 모델

## 측정 조건
- 사전학습 모델: amazon/chronos-bolt-small, 장치 cpu, torch 2.14.1+cpu, CPU 스레드 3, gpu-run.sh 락 안에서 실행
- 시험 시점: 2026-10-06~2026-10-20 중 60분 간격 300개 (기본 보고서 06_pretrained.md 와 같은 고르는 법), 검증 시점(가중치 선택용) 300개
- GRU: models/forecast_gru.pt (있음)
- 앙상블: 평균 = 0.5·GRU + 0.5·Chronos 중앙값 (고정), 가중평균 = w·GRU + (1-w)·Chronos, w ∈ 0~1 (0.05 간격) — 검증 기간 시점에서 항목·지평별로 고름
- 주의: GRU 는 검증 기간으로 조기 종료했으므로 검증 기간 GRU 오차가 시험보다 약간 낙관적이다 → w 가 GRU 쪽으로 치우칠 수 있다
- Chronos-2 (amazon/chronos-2): ok, 예측 시간(초) {'chronos2': 165.1, 'chronos2+cov': 1083.3}
- Chronos-2 공변량: 같은 공간의 나머지 두 항목·외기 온습도(과거만), 시간표 사용 여부(과거 + 앞으로 60분, 미리 아는 값). 공변량 결측은 앞값으로 채움
- 모든 방법이 값이 있는 시점만 채점 (같은 시점 비교)
- 실행 시간 1373s
