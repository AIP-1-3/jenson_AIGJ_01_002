## 질의응답 대비에 쓸 약점 (예상 질문)

- 과제 3 −30% 를 왜 못 넘었나 → 현재값 유지가 이미 강함(CO₂ 가 천천히 변함), 회의실은 한 번에 922ppm 씩 오르고 센서 1대, 회의 시각이 불규칙(3.2).
- 과제 4 탐지율이 1차 72% 에서 3차 65% 로 왜 내려갔나 → 헛경보를 1.2→0.4회/일로 줄이려고 값 고정 판정 길이를 정상 기간에서 배웠더니 빈 회의실의 830분 정체와 3시간 고장이 구별되지 않음. 맞바꿈을 의도적으로 고름(3.3).
- 사용 여부 0.965 는 왜 버렸나 → 시간표를 정답으로 만들고 시각을 입력에 넣어 누출. 센서만 0.806(6.4).
- 시험 기간을 정말 안 봤나 → 임계값·α·조기 종료·조합 선택 모두 검증 기간, 시험은 마지막 채점에만(4장).
- 서비스가 하루 동안 죽어 있던 걸 왜 몰랐나 → `is-active` 만 봤음. 지금은 `/health` 와 NRestarts 로 확인(6.5).
